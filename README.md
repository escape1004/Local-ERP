# Local ERP

Local ERP는 컴퓨터에 보관한 파일과 관련 정보를 한곳에서 정리하고 찾아볼 수 있는 개인용 자료 관리 프로그램입니다.

폴더만으로 구분하기 어려운 이미지, 동영상, 문서, 압축파일 등의 정보를 원하는 레코드로 기록하고, 검색하거나 미리 볼 수 있습니다. 웹에서 본 자료는 내장 브라우저로 열어 두고, 필요한 내용을 레코드로 옮길 수도 있습니다. 데이터는 사용자의 PC에 저장됩니다.

## 다운로드 및 설치

[**Local ERP v1.1.25 Windows 설치 파일 다운로드**](https://github.com/escape1004/LCERP/releases/download/v1.1.25/Local-ERP-Setup-1.1.25.exe)

다운로드한 `Local-ERP-Setup-1.1.25.exe` 파일을 실행하고 안내에 따라 설치하면 됩니다. 이전 버전이 설치되어 있다면 기존 데이터와 설정을 유지한 상태로 업데이트됩니다.

다른 버전과 전체 배포 파일은 [GitHub Releases](https://github.com/escape1004/LCERP/releases)에서 확인할 수 있습니다.

## 이런 자료를 관리할 때 유용합니다

- 이미지와 동영상처럼 파일 수가 많은 개인 자료
- 제목, 날짜, 태그, 평점 등 파일과 함께 기록할 정보
- 서로 연관된 작품, 인물, 프로젝트 또는 문서
- 웹에서 찾아 두고 나중에 다시 열어볼 자료
- 용도에 따라 완전히 분리해서 관리하고 싶은 자료 모음

## 주요 기능

### 프로필과 카테고리로 자료 나누기

- 프로필을 만들어 용도별 데이터를 완전히 분리할 수 있습니다.
- 상위 카테고리와 하위 카테고리로 자료 구조를 구성할 수 있습니다.
- 사이드 메뉴에서 카테고리 순서를 드래그로 바꾸고, 구분선을 넣어 메뉴를 나눌 수 있습니다.
- 카테고리를 다른 프로필로 옮기거나, 구조만 JSON으로 추출한 뒤 다시 붙여 넣을 수 있습니다.
- 환경설정에서 카테고리 순서 변경을 잠글 수 있습니다.

### 원하는 방식으로 레코드 기록

- 카테고리마다 필요한 입력 항목을 직접 만들 수 있습니다.
- 텍스트, 긴 글, 숫자, 백분율, 날짜, 체크박스, 선택 목록, 파일, 관계형 항목을 지원합니다.
- 관계형 항목으로 다른 카테고리의 레코드를 서로 연결할 수 있습니다.
- 최상위 카테고리 레코드끼리는 관계형 항목과 별개로 관련 레코드를 직접 연결할 수 있습니다. 연결된 레코드가 있을 때만 상세 화면에 위젯이 나타납니다.
- 필수값, 중복 불가, 목록에서 숨기기, 다중 선택, 접두사·접미사 표시를 항목별로 정할 수 있습니다.
- 파일명 규칙으로 파일 이름에서 제목, 날짜, 관계형 값 등을 자동으로 채울 수 있습니다.
- 텍스트에 `#태그`를 쓰면 목록에서 해시태그로 강조됩니다.
- 주소가 보이면 앱 브라우저나 외부 브라우저에서 열거나, 클릭해서 복사할 수 있습니다.

### 빠른 검색과 편리한 목록

- 테이블 보기와 썸네일 중심의 갤러리 보기를 제공합니다.
- 검색, 필터, 정렬로 원하는 자료를 찾을 수 있습니다. 날짜는 달력으로, 선택·관계형은 목록에서 골라 찾을 수 있습니다.
- 번역이 켜진 항목은 원문과 번역문을 따로 검색할 수 있습니다.
- 이미지, 동영상, 압축파일만 골라 볼 수 있습니다.
- 갤러리에서 카드에 보여줄 항목을 고르고, `Ctrl + 휠`로 카드 크기를 조절할 수 있습니다.
- 갤러리 동영상 썸네일에는 재생 길이가 표시되고, 파일 확장자는 왼쪽 아래에 보입니다.
- 테이블과 갤러리에서 동영상 썸네일에 마우스를 올리면 미리보기가 재생됩니다.
- `Ctrl + R`을 누르면 현재 카테고리에서 임의의 레코드 하나를 바로 열 수 있습니다.
- CSV 또는 Excel 파일로 여러 레코드를 한 번에 가져오거나 내보낼 수 있습니다.
- 한 항목에 여러 값을 넣어 레코드를 한꺼번에 추가할 수도 있습니다.

### 앱 안에서 파일 확인

- 이미지와 동영상을 별도 프로그램 없이 바로 볼 수 있습니다.
- 동영상은 재생 위치를 북마크하고, 구간 반복, 배속, PIP, 전체화면을 사용할 수 있습니다.
- 같은 폴더의 자막 파일을 자동으로 찾아 보여 주고, 크기·색상·싱크를 조절할 수 있습니다.
- 압축파일 내부의 이미지, 동영상, 텍스트를 차례로 넘기거나 검색해서 찾아볼 수 있습니다.
- 필요한 이미지나 영상 장면을 커스텀 썸네일로 지정할 수 있습니다. 직접 등록한 썸네일은 작은 아이콘으로 구분됩니다.

### 한눈에 보는 대시보드

- 카테고리별 레코드 수와 파일 종류를 확인할 수 있습니다.
- 최근 추가한 자료와 자주 열어본 레코드를 볼 수 있습니다.
- 원본 파일 누락이나 잘못된 관계 연결을 경고로 확인할 수 있습니다.
- 하위 카테고리에서는 이 레코드를 참조하는 상위 레코드와 조회 순위를 함께 볼 수 있습니다.

### 앱 안에서 쓰는 브라우저

사이드 메뉴의 `브라우저` 또는 레코드에 있는 주소를 `앱 브라우저에서 열기`로 실행합니다. 앱 본체와 별도 창으로 열리며, 탭과 단축키는 일반적인 웹 브라우저와 비슷합니다.

- 탭, 주소창 검색, 북마크, 북마크 바, 새 탭 바로가기를 지원합니다.
- 닫은 탭을 다시 열고, 탭을 복제하거나 드래그해서 순서를 바꿀 수 있습니다.
- 시작할 때 새 탭을 열거나, 이전 창과 탭을 그대로 이어서 볼 수 있습니다.
- 페이지에서 `Ctrl + F`로 글을 찾고, 방문 기록과 다운로드 기록을 볼 수 있습니다.
- 이미지·영상을 다른 이름으로 저장하거나, 페이지에 있는 이미지·영상을 골라 한꺼번에 저장할 수 있습니다. YouTube와 DRM으로 보호된 영상은 저장할 수 없습니다.
- 레코드에 이미 등록된 주소는 북마크 별이 남색으로 표시되고, 북마크로 중복 저장되지 않습니다.
- 로그인을 이 PC에만 암호화해 저장하고, 필요할 때 확인 후 채워 넣습니다.
- 광고·트래커와 직접 지정한 도메인을 차단할 수 있습니다. 꺼져 있는 탭만 음소거하는 옵션도 있습니다.
- 페이지에 맞는 사용자 스크립트를 저장해 실행할 수 있습니다.
- OpenAI API 키를 설정하면 페이지를 번역하거나, 현재 탭을 보면서 AI와 대화할 수 있습니다.
- `Ctrl + Shift + C` 또는 페이지 우클릭으로 현재 페이지를 레코드로 등록할 수 있습니다. 화면의 글을 골라 항목에 넣을 수 있으며, 아직 베타 기능입니다.

### 선택해서 사용하는 자동 번역

- 번역이 필요한 텍스트 항목만 자동 번역 대상으로 설정할 수 있습니다.
- 한국어, 영어, 일본어, 중국어를 대상 언어로 선택할 수 있습니다.
- 번역 품질과 비용에 맞춰 OpenAI 모델을 선택할 수 있습니다.
- 자동 번역 결과를 직접 수정하거나, API 키 없이 번역문을 수동으로 입력할 수도 있습니다.
- 자동 번역은 사용자가 버튼을 눌렀을 때만 실행됩니다.
- 목록에서는 번역문을 툴팁으로 보거나, 원문 자리에 바꿔 보도록 선택할 수 있습니다.

### 데이터 보호와 정리

- 데이터베이스를 원하는 폴더에 즉시 백업할 수 있습니다.
- 자동 백업을 켜거나 끄고 실행 간격을 설정할 수 있습니다.
- 레코드와 연결되지 않은 썸네일 파일을 안전하게 찾아 정리할 수 있습니다.
- 앱 비밀번호, 로그인 실패 잠금, 자리 비움 시 자동 잠금으로 다른 사람의 접근을 제한할 수 있습니다. 영상을 보고 있는 동안에는 자리 비움 잠금이 걸리지 않습니다.

### 보기 환경 설정

- UI 확대 배율과 썸네일 크기 및 맞춤 방식을 조절할 수 있습니다.
- 갤러리 기본 확대 배율과 동영상 탐색 간격을 설정할 수 있습니다.
- 창 위치 기억, 동영상 자동 재생, 백그라운드 음소거 여부를 선택할 수 있습니다.
- 설치된 앱에서는 새 버전을 확인하고 앱 안에서 업데이트할 수 있습니다.

## 시작하기

1. 배포된 설치 파일을 실행해 Local ERP를 설치합니다.
2. 앱을 실행한 뒤 새 프로필을 만듭니다.
3. 자료를 분류할 카테고리를 만들고 필요한 입력 항목을 추가합니다.
4. 카테고리에서 레코드를 추가하고 관련 파일과 정보를 입력합니다.
5. 목록과 대시보드에서 자료를 검색하고, 필요하면 내장 브라우저로 웹 자료를 이어서 봅니다.

처음에는 제목과 파일 항목만으로 간단히 시작한 뒤, 필요할 때 날짜나 태그 같은 항목을 추가하는 방식을 권장합니다.

## 알아두어야 할 점

- 첨부파일은 앱 내부로 복사되지 않고 컴퓨터에 있는 원본 위치를 참조합니다.
- 원본 파일을 이동하거나 이름을 변경하면 앱에서 파일을 찾지 못할 수 있습니다.
- 데이터베이스 백업에는 원본 첨부파일이 포함되지 않습니다. 중요한 원본 파일은 별도로 백업해야 합니다.
- 앱에서 여는 외부 주소는 웹 주소(HTTP/HTTPS)만 허용합니다.
- 자동 번역과 페이지 번역을 사용할 때만 해당 텍스트가 OpenAI API로 전송됩니다.
- OpenAI API 키와 사용 요금은 사용자가 직접 관리해야 합니다. 키는 이 PC에 암호화되어 저장됩니다.
- 브라우저에서 페이지를 레코드로 등록하는 기능은 베타입니다. 모든 페이지와 항목에서 동작하지 않을 수 있습니다.
- 사용자 스크립트는 직접 작성한 코드가 페이지에서 실행되므로, 신뢰할 수 있는 내용만 저장하세요.
- 관련 레코드 직접 연결은 최상위 카테고리에서만 사용할 수 있습니다.

## 주요 단축키

### 목록

- `Ctrl + F`: 검색창으로 이동
- `Ctrl + N`: 새 레코드 추가
- `Ctrl + R`: 현재 카테고리에서 임의의 레코드 열기
- `F2`: 선택한 레코드 수정
- `F5`: 현재 목록 새로고침
- `Ctrl + ←` / `Ctrl + →`: 이전 또는 다음 페이지로 이동
- `↑` / `↓`: 목록에서 레코드 선택 이동

### 파일 보기

- `Esc`: 뷰어 닫기
- `Space`: 동영상 재생 또는 일시정지
- `F`: 전체화면 켜기 또는 끄기
- `,` / `.`: 동영상에서 이전 또는 다음 프레임으로 이동
- `[` / `]`: 재생 속도 조절

### 브라우저

- `Ctrl + T`: 새 탭
- `Ctrl + W`: 탭 닫기
- `Ctrl + Shift + T`: 닫은 탭 다시 열기
- `Ctrl + L`: 주소창으로 이동
- `Ctrl + F`: 페이지에서 찾기
- `Ctrl + Shift + C`: 현재 페이지를 레코드로 등록 (베타 기능)
- `Alt + ←` / `Alt + →`: 이전 또는 다음 페이지

앱 화면별 전체 단축키는 환경설정의 `단축키` 탭에서 확인할 수 있습니다.

## 문제가 생겼을 때

### 첨부파일이나 미리보기가 보이지 않는 경우

- 원본 파일이 이동되거나 삭제되지 않았는지 확인합니다.
- 레코드에 저장된 파일 경로가 올바른지 확인합니다.
- 대시보드에서 파일 누락 경고를 확인합니다.

### 자동 번역을 사용할 수 없는 경우

- 환경설정의 `번역` 탭에서 OpenAI API 키가 저장되어 있는지 확인합니다.
- OpenAI API 크레딧과 사용 한도가 남아 있는지 확인합니다.
- 선택한 모델을 API 계정에서 사용할 수 있는지 확인합니다.
- API 키가 없어도 번역문은 직접 입력할 수 있습니다.

### 브라우저 페이지가 열리지 않거나 저장이 안 되는 경우

- 주소가 `http://` 또는 `https://`로 시작하는지 확인합니다.
- 광고·트래커 차단이나 특정 도메인 차단이 켜져 있으면 해당 사이트가 막혀 있는지 확인합니다.
- 영상 저장은 YouTube와 DRM 보호 영상에는 사용할 수 없습니다. 일부 사이트는 재생을 시작한 뒤에야 영상을 인식합니다.

### 데이터 용량이 계속 늘어나는 경우

- 환경설정의 `데이터` 탭에서 `썸네일 파일 정리`를 실행합니다.
- 정리 기능은 레코드가 참조 중인 썸네일을 보존하고 연결되지 않은 파일만 삭제합니다.

### 1.1.25 업데이트

- 목록과 화면의 “항목” 표현을 “레코드”로 통일했습니다.
- 내장 브라우저에 페이지 찾기, 방문 기록, 다운로드, 이미지·영상 저장, 탭 드래그를 추가했습니다.
- 현재 페이지를 레코드로 등록하는 기능을 베타로 추가했습니다.
